# GitHub Pages application

Open index.html through an HTTPS or localhost web server. The detector and localizer are embedded as ONNX bytes. A pinned ONNX Runtime Web 1.31.1 runtime is loaded from jsDelivr; user SGY files and reviews are processed and stored on-device. The optional Lands Department road map requests tiles for the visible viewport. SGY track vectors remain on-device. An external Google Maps link shares the selected location when opened.

Source modules are in browser/; rebuild with python tools/build_browser.py.
