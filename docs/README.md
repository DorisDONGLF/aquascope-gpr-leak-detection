# GitHub Pages application

Open index.html through an HTTPS or localhost web server. The detector and localizer are embedded as ONNX bytes. A pinned ONNX Runtime Web 1.31.1 runtime is loaded from jsDelivr; user SGY files and reviews are processed and stored on-device. Google Maps is optional and sends the selected location to Google only after Show map is enabled.

Source modules are in browser/; rebuild with python tools/build_browser.py.
